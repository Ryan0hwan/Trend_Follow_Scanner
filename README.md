# 미너비니 추세 템플릿 스캐너

S&P 500과 내 관심종목(약 680종목)에서 마크 미너비니 추세 템플릿 8개 조건을 매일 확인해, 디스코드로 두 가지 목록을 따로 보냅니다.

| 목록 | 내용 |
|---|---|
| **② 신규 진입 (B)** | 8개 조건을 모두 만족하기 시작한 지 **10거래일 이내**인 종목. 50일선보다 25% 넘게 오른 과열 종목은 제외. 진입한 지 얼마 안 된 순으로 정렬 |
| **① 8개 모두 충족** | 오늘 8개 조건을 모두 만족하는 종목 전체. S&P 500과 관심종목으로 나눠 RS 순으로 정렬 |

## 추세 템플릿 8개 조건

| # | 조건 |
|---|---|
| 1 | 주가 > 150일선, 주가 > 200일선 |
| 2 | 150일선 > 200일선 |
| 3 | 200일선이 1개월(21거래일) 전보다 높음 |
| 4 | 50일선 > 150일선, 50일선 > 200일선 |
| 5 | 주가 > 50일선 |
| 6 | 52주 저점 대비 +30% 이상 |
| 7 | 52주 고점 대비 -25% 이내 |
| 8 | RS 70 이상 |

**RS**는 상대강도 대시보드와 같은 계산입니다. 3개월 수익률 40% + 6·9·12개월 수익률 각 20%를 가중합해 전체 종목 중 백분위(1~99)로 매깁니다. 신규 진입 판단에 쓰려고 최근 11거래일 각각의 RS를 따로 계산합니다.

기본 필터: 주가 $5 이상, 50일 평균 거래대금 $500만 이상.

## 디스코드 표 보는 법

| 열 | 의미 |
|---|---|
| RS | 오늘 RS 점수 |
| DAYS | 8개 조건을 연속으로 만족한 거래일 수. 1이면 오늘 처음 진입, `10+`는 진입한 지 10거래일 넘음 |
| LAST | 종가 |
| 50D% | 50일선 대비 위치(%). 클수록 단기 과열 |
| HI% | 52주 고점 대비(%). 0에 가까울수록 신고가 근처 |
| LO% | 52주 저점 대비(%) |
| 1M% / 3M% | 1개월·3개월 수익률 |

## 실행 시각

평일 한국 시각 **06:55** (미국 장 마감 후 확정 일봉 기준). GitHub 특성상 5~30분 늦을 수 있습니다.

## 설치 (새 저장소, 약 10분)

### 1. 디스코드 채널·웹후크
1. 채널 목록 **채팅 채널** 옆 **+** → 새 채널 생성 (예: `추세템플릿`)
2. 새 채널 옆 **⚙** → **연동** → **웹후크** → **새 웹후크**
3. 생긴 봇을 펼쳐 **채널**이 새 채널인지 확인 → **웹후크 URL 복사**

### 2. GitHub 저장소
1. 오른쪽 위 **+** → **New repository** → 이름 입력 (예: `trend-scanner`) → **Public** → **Create repository**
2. **uploading an existing file** → `trend.py`, `watchlist.txt`, `requirements.txt`, `README.md` 끌어다 놓기 → **Commit changes**
3. **Add file → Create new file** → 이름 칸에 `.github/workflows/main.yml` 입력 → zip 안의 `main.yml` 내용 붙여넣기 → **Commit changes**

### 3. 웹후크 주소 등록
1. **Settings** → 왼쪽 **Secrets and variables** → **Actions**
2. **New repository secret** → Name: `DISCORD_WEBHOOK_URL` / Secret: 1-3에서 복사한 주소 → **Add secret**

### 4. 테스트
1. **Actions** 탭 → 왼쪽 **Trend Template Scanner** → **Run workflow** → **Run workflow**
2. 몇 분 뒤 새 채널에 요약 메시지, ② 신규 진입 표, ① 전체 표가 차례로 오면 끝

이 스캐너는 결과를 저장소에 저장하지 않으므로 상대강도 대시보드와 달리 저장 권한·Pages 설정이 필요 없습니다.

## 설정 바꾸기 (`trend.py` 맨 위)

| 항목 | 현재값 | 의미 |
|---|---|---|
| `RS_MIN` | 70 | 조건 8의 RS 하한 |
| `LOW_UP_PCT` | 30 | 조건 6, 52주 저점 대비 최소 상승률(%) |
| `HIGH_DOWN_PCT` | 25 | 조건 7, 52주 고점 대비 최대 하락률(%) |
| `SLOPE_DAYS` | 21 | 조건 3, 200일선 상승 확인 기간(거래일) |
| `NEW_DAYS` | 10 | B 목록, 진입 후 며칠 이내까지 보여줄지 |
| `MAX_ABOVE_50` | 25 | B 목록, 50일선 위 몇 %까지 허용할지 |

## 알아둘 점

- ① 전체 목록은 강세장에서 100종목 넘게 나올 수 있어 디스코드 메시지가 여러 개로 나뉘어 옵니다.
- 상장 약 11개월(232거래일) 미만 종목은 200일선 기울기를 계산할 수 없어 빠집니다.
- 시세는 야후 파이낸스 무료 데이터이고, 야후에 없는 티커는 빠집니다.
